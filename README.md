# EduLedger

## 🚀 Getting Started / Setup Instructions

Sundan ang mga hakbang na ito para mapatakbo ang project sa iyong computer:

### 1. Magbukas ng Terminal o Git Bash sa folder kung saan mo gustong ilagay ang project.

### 2. I-clone ang Repository
git clone https://github.com/jaxpacleb/eduledger.git

### 3. Pumasok sa folder ng project:
cd eduledger

### 4. I-install ang lahat ng kailangang packages/modules:
npm install

### 5. Patakbuhin ang local server:
npm run dev

### 6. Buksan ang browser: 
Pumunta sa link na lalabas sa terminal 'http://localhost:5173'.
